«Пересчитать» и «Удалить» в журнале расходов

У каждой строки журнала появляются два действия, и оба — пиктограммами: круговая стрелка «Пересчитать» считает сумму строки заново по текущим ценам проекта, корзина «Удалить» убирает строку из журнала. У смены действий три — рядом с ними прежняя «Сессии» (список). Итог проекта в обоих случаях пересобирается с сервера суммой оставшихся строк: фронт деньги не считает. Оба действия необратимы, поэтому каждое спрашивает подтверждение окном.

Пиктограммы действий строки

  • Сессии — из каких сессий сложилась смена
  • Пересчитать — сумма строки заново по текущим ценам
  • Удалить — строка исчезнет из журнала
